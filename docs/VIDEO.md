# Video script (under 3 minutes)

Rules: the moment in the first 30 seconds, every spoken number read off a screen element, say "Nebius Token Factory", "Nemotron", and "Tavily" out loud while they are on screen, no music you do not own. Record at 1920x1080, browser zoom 110 percent, the extension loaded, the demo workspace already seeded (click "Load demo shop" before recording, then run a check on the toy so an alert exists).

| Time | Say | Do | See |
|---|---|---|---|
| 0:00 to 0:12 | "I sell on Etsy. This is a wooden stacking toy I import from China. Shop Rules is the compliance clerk that quotes its sources." | On the Etsy listing in Chrome, hold Alt, hover the product, press Alt+Shift+S | The overlay slides in: title, price, rules that touch it, the open alert |
| 0:12 to 0:30 | "It already knows this listing. Tariff rules, product safety rules for a children's toy, the nexus thresholds for the states I ship to. And one alert: the de minimis exemption for low-value imports from China is suspended. Read the counter." | Point at the evidence counter in the overlay | "4 proposed, 4 backed, 0 rejected" (read what the screen says) |
| 0:30 to 0:55 | "Open it in Shop Rules. Every claim carries the sentence it came from. This one is from the Federal Register. The verifier is a separate program: if the quote is not in the text Tavily extracted, the claim is rejected and stays visible as rejected. Here is one it dropped." | Click "Open in Shop Rules", scroll the alert page to the claims, click a source link | The alert page: the action block, the evidence bar, Backed and Rejected labels, the quote block, the source opens in a tab |
| 0:55 to 1:15 | "How it works: Tavily Search finds the official pages, restricted to CBP, USTR, the Federal Register, CPSC. Tavily Extract pulls the chunks that matter. Nemotron 3 Ultra on Nebius Token Factory decides whether the change touches this product and drafts the step. Nano does the fast work: it classified the listing in a few seconds." | Open the product page, show the watch rules with their domains, then the profile card | Rules grouped by family with domains, HTS candidate with confidence, origin |
| 1:15 to 1:45 | "Now the coding agent. Forge a check. Ultra writes a Python extractor for this one fact. Nano writes the tests from the facts the verifier already backed. A Token Factory sandbox runs them. If they fail, Ultra revises." | Click "Forge a check", wait on the stepper, open the forge page | The timeline: Sources, Write (Ultra), Tests (Nano), Run (sandbox, pass or fail), the code and tests side by side, the extracted value |
| 1:45 to 2:10 | "The action is a reprice with the price that keeps my margin. One click copies it. Dismiss an alert with a reason and it becomes a standing instruction the next check follows." | Back on the product page, click "Draft reprice", then dismiss the Prop 65 alert with "we already print the warning" | The success banner, then the standing instruction appears |
| 2:10 to 2:35 | "The receipt shows which model did what and what all-Ultra would have cost. Everything you saw is a live call: Tavily, Nemotron on Token Factory, the sandbox. Nothing replayed." | Open the cost receipt | By-model bars, the saved percentage |
| 2:35 to 2:50 | "Not built: no store API, no order data, the verifier checks presence not meaning. It is all in the repo under docs." | Show docs/not-built.md in the repo | The file |
| 2:50 to 3:00 | "Shop Rules. Tavily reads the official page. Nemotron decides. The verifier drops what it cannot quote. You approve." | Back to the Watchlist feed | The feed with the metric strip |

Never say: "always accurate", "real-time", "autonomous" without "you approve", "live" about anything replayed (nothing is), a number that is not on screen.

Fallbacks: if the forge sandbox is not configured on the deployment, say "the sandbox step is not configured on this deployment; the code and tests are still written" and show the Not run label. If a check returns no new alerts, open an existing alert instead of running one on camera.
